THE STORY

Chapter 01

An image is just a grid of numbers

  • Before a network can "see" anything, we have to agree on what a picture actually is to a computer.
  • It is not a scene.
  • It is a table of brightness values.
HOLD ONTO THIS
  • Every pixel is a number.
  • A grayscale image is one grid.
  • A color image is three grids stacked together, one each for Red, Green, and Blue.
  • Everything a CNN does is arithmetic on these numbers.

Meet the pixels

Hover any cell to read its value. Switch between one grayscale grid and three color channels.

hover a pixel

Why the number matters

  • A value near 0 is dark, while a value near 255 is bright.
  • The network never sees the cat, the digit, or the road. It only ever sees these numbers and learns which patterns of numbers matter.
  • Our whole job in the next chapters is to turn this grid into a smaller, smarter grid, again and again, until it can name what it is looking at.
Chapter 02

The filter is a tiny grid of weights

  • A filter (also called a kernel) is a small square of numbers that slides over the image and looks for one specific pattern.
  • The numbers inside it are the weights.
  • Each filter also carries a single bias.

HOLD ONTO THIS
  • Weights begin as random numbers, not clean patterns.
  • Training nudges them until useful filters emerge on their own.
  • The edge and blur presets are just to show what a learned filter can look like.
  • You never have to hand-write them (Hey, that's what CNN will do for you for free!).

Chapter 04

Color images: three channels, one feature map

  • A color image has three grids, so the filter also has three slices, one per channel.
  • The part students miss: the three channel results are added together.
  • Three channels in, still one feature map out.
THE MOMENT TO REMEMBER
  • The depth of a filter always equals the depth of its input.
  • We convolve each channel with its own slice, then sum the three results and add one bias.
  • A single filter over an RGB image produces a single feature map, not three.

Chapter 05

Stride and padding set the output size

  • Two knobs decide how big the feature map comes out.
  • Stride is how far the filter jumps each move.
  • Padding is a border of zeros we add around the input so the filter can reach the edges.

Valid vs Same padding

Valid padding

No padding at all, P = 0. The filter only sits where it fully overlaps the image, so the output is smaller than the input. "Valid" means only valid, fully-covered positions are used.

Same padding

Add just enough zeros so the filter can cover the edges. With stride 1, the output matches the input exactly.

With a larger stride the output cannot equal the input, so "same" means it shrinks by the stride to the nearest step. The padding is then chosen to hit that target and split across both sides.

RULE OF THUMB
  • Bigger stride shrinks the map faster.
  • Padding buys back size and protects the edge pixels from being under-counted.
  • Same keeps dimensions steady through a layer; Valid lets them shrink.

Chapter 07

Pooling shrinks the map

  • After convolution we usually downsample.
  • A small window slides over the feature map and replaces each patch with a single summary value.
  • No weights, no learning, just a rule.
  • This keeps the strongest signals and cuts the size.
window 0

MAX vs AVERAGE
  • Max pooling keeps the single strongest response in each patch, so it holds onto sharp features.
  • Average pooling smooths the patch into its mean.
  • Max is the common default in modern CNNs.
Chapter 08

Activation adds the nonlinearity

  • Convolution and pooling are still, at heart, adding and averaging.
  • Stack a hundred of them and you still only get a linear machine.
  • The activation function breaks that.
  • The workhorse is ReLU: keep positives, clamp negatives to zero.

THE BIG WHY
  • Weight sharing gives translation invariance: a feature learned in one corner is detected everywhere for free, and with a fraction of the parameters.
  • That is why convolution, not dense layers, is the right tool for images.

THE ONE-SENTENCE SUMMARY
  • A CNN repeatedly turns a grid of numbers into a smaller, richer grid of numbers.
  • It learns its own filters as it goes.
  • Only at the very end does it ask a plain network to name what it found.

The shape of the layers

  • Notice the pattern in the dimensions.
  • Spatial size (height and width) tends to fall through the network, while depth (the channel count) tends to rise.
  • Early layers see edges and textures; deeper layers, thanks to the growing receptive field, see whole objects.

Chapter 13

Transpose convolution: growing an image from a vector

  • Everything so far made images smaller: convolution and pooling shrink a picture down to a short vector of features.
  • Generators and decoders run the other way: they start from a small vector and grow it into a full image.
  • The operation that enlarges a feature map is the transpose convolution.
THE MIRROR
  • Ordinary convolution maps many pixels to one number, so it shrinks.
  • Transpose convolution maps one number to many pixels, so it grows.
  • It is the same weighted-window idea run backward, which is why it is also called a fractionally strided or up convolution.

From a latent vector to an image

  • A generator starts with a random latent vector, here a list of 100 numbers.
  • A dense (fully connected) layer projects it into 7 × 7 × 128 = 6272 numbers, and we reshape that flat list into a 7 × 7 grid that is 128 channels deep.
  • That small, deep block is the seed.
  • Transpose convolutions then upsample it, each one doubling height and width while using fewer channels, until we reach a 28 × 28 image.
  • The exact sizes (100, the 7 × 7 seed, 128 channels) are design choices; a 7 × 7 seed is picked so that two doublings land on 28 × 28.
spatial the height × width of the map, which grows channels the depth, how many feature maps, which shrinks

The generator pipeline

The architecture is fixed. Press Generate to draw a new random latent vector and watch a different image come out the end.

The intuition to say out loud in class: the stride S = 2 is what actually drives the upsampling. The F = 4 and P = 1 are then chosen so the result lands on exactly twice the input, a clean doubling.

How one transpose conv step upsamples

  • We use a tiny 2 × 2 input just so every stamp stays visible; the same rule works at any size.
  • This example uses a 3 × 3 kernel, stride S = 2, and no padding (P = 0).
  • Each input value is multiplied by the whole kernel, and that scaled kernel is stamped into the output at a strided position.
  • Where stamps overlap, the values add up.

SIZE GOES UP
  • With stride S, kernel F, and input size I (no padding), the output is O = (I − 1)·S + F.

  • Padding then trims the border to hit exact targets, like an exact doubling.
Chapter 14

Skip connections: how networks got very deep

  • Stacking more layers should make a network stronger.
  • In practice, past a point, very deep plain networks get harder to train and actually perform worse, even on the training set.
  • Skip connections are the fix that let ResNet reach 50, 101, even 152 layers.
THE PROBLEM
  • A deeper plain network can represent everything a shallower one can; just make the extra layers do nothing.
  • Yet training fails to find that solution: the signal and the gradients weaken as they pass through many layers.
  • This is the degradation problem, and it is an optimization failure, not overfitting.

The residual block

Instead of asking a block to learn the whole mapping, we let it learn only the change to add to its input. Toggle the skip connection to see the difference.

Why it works

  • First: if the best thing a block can do is nothing, the network only has to push F(x) toward zero and the identity passes straight through, so extra depth can no longer hurt.
  • Second: the skip path is a gradient highway, so during backpropagation the +x term sends gradients directly back to earlier layers and they do not vanish.
HOLD ONTO THIS
  • A residual block computes y = F(x) + x.
  • The block learns the residual F(x), and the identity shortcut carries x forward.
  • This single idea is why networks with hundreds of layers train at all, and it now appears almost everywhere, including the transformers behind large language models.
Chapter 15

The 1×1 convolution: mixing channels

  • A 1×1 filter sounds pointless: how can a single-pixel window learn anything?
  • The trick is depth: it looks at one spatial position but every channel at once, so it mixes and reshapes channels without touching spatial patterns.
  • It is the cheapest way to change how many channels a layer has.

Walk the three steps

1
Squeeze, 1×1 conv, 256 → 64. A 1×1 filter reads all 256 channels at a single pixel and outputs one number. Using 64 of them compresses each pixel's 256-number description into a 64-number summary. Spatial size is untouched; this only shrinks the channel count.
1×1×256×64 = 16,384 weights
2
Work, 3×3 conv, 64 → 64. Now do the real spatial detection (edges, curves, textures), but on the compact 64-channel stack instead of 256. Because cost scales with input channels × output channels, doing the 3×3 at 64×64 is about 16× cheaper than at 256×256.
3×3×64×64 = 36,864 weights
3
Restore, 1×1 conv, 64 → 256. Expand back up to 256 channels. Two reasons: the block sits inside a residual connection, so the output must match the input x's 256 channels for the shortcut add to line up, and the next block expects 256 channels coming in.
1×1×64×256 = 16,384 weights

The expensive 3×3 runs only while the stack is small. The two 1×1 layers are the cheap squeeze and restore around it, like summarizing a long document, editing the short summary, then expanding it back.

THE PAYOFF
  • The bottleneck uses about 8.5× fewer parameters than a direct 3×3, with the same final output shape and the same effective spatial reach.
  • That efficiency is what let ResNet stack so many blocks without the parameter count exploding.
Chapter 16

Global Average Pooling (GAP)

  • Global Average Pooling is actually very simple.
  • For each feature map (channel) coming out of a CNN, take the average of all its spatial values.
  • Replace the entire feature map with that one number.

  • That entire 3×3 feature map becomes a single number: 3.

Scaling up to many channels

  • Now suppose the CNN has 512 channels, so the block is 512 × 7 × 7.
  • GAP independently averages each 7×7 feature map, which gives a vector of size 512:
WHY IS IT CALLED "GLOBAL"?
  • It averages over the entire spatial area of each feature map.
  • Regular average pooling might average small windows, 2×2 at a time.
  • Global average pooling says: use the whole feature map as one pooling region.

What does that number mean?

  • Suppose one channel has learned to detect something like dog fur.
  • Its feature map might look roughly like this, where high values mean "I found the feature here":
  • GAP does not care exactly where the feature occurred.
  • It summarizes one thing: overall, how strongly was this feature present in the image?
  • So each channel contributes one number describing how strongly its learned feature appeared.
THE MENTAL MODEL

Chapter 18

U-Net: growing the picture back

  • Everything so far has squeezed an image down to features.
  • Some tasks need the opposite: a full-resolution answer for every pixel.
  • U-Net is the classic design for that, and it reuses two tools you already have: transpose convolution (Chapter 13) and skip connections (Chapter 14).
ONE NEW WORD
  • A CNN that shrinks an image into features is an encoder.
  • A decoder is its mirror image that grows those features back into a full-size output.
  • Together they form an encoder / decoder.
  • You will meet this same shape next week as the autoencoder; here it is doing segmentation.

Why grow the image back at all? Classification gives one label for the whole image. Segmentation gives a label for every pixel: tumor vs healthy tissue, road vs car vs sky. To label each pixel we have to return to the original resolution, so the network needs an expanding path, not just a shrinking one.

The U shape

The left path shrinks the image into features (encoder). The right path grows it back (decoder). The dashed links copy fine detail straight across so it is not lost.

WHY THE SKIPS MATTER HERE
  • Pooling on the way down throws away fine spatial detail, exactly what you need to draw a crisp boundary.
  • The dashed links hand the high-resolution feature maps from the encoder straight to the matching decoder level, so edges stay sharp instead of blurry.
  • Same skip-connection idea as ResNet, used here to preserve detail rather than to ease training.

You will see this U everywhere: medical image segmentation, satellite and road maps, background removal, and, in a scaled-up form, as the backbone of modern diffusion image generators. It ties together convolution, pooling, transpose convolution, and skip connections in one shape.

Chapter 19

A first look at attention

  • So far every feature map is treated equally.
  • Attention changes that: it is a set of learned weights that say which features matter most right now.
  • The network can turn some up and others down instead of giving them all the same say.
A TASTE, NOT THE FULL STORY
  • Full attention is the heart of transformers, which is a lecture of its own.
  • Here we look at the simplest, most CNN-native version so the idea feels familiar before we take it further.

Channel attention (squeeze and excitation)

The network looks at all 8 channels, decides how important each one is (a weight from 0 to 1), and rescales them. Press Recalibrate to let it choose new weights and watch channels get boosted or damped.

It can also learn where to look

The same idea works over space, not just channels. A spatial attention map is a learned heatmap that brightens the regions worth focusing on and dims the rest, so later layers spend their effort where it counts.

WHERE THIS GOES NEXT
  • CNN attention reweights feature maps the network already computed.
  • In a transformer, attention goes further: every location computes, from the data itself, how much to attend to every other location.
  • That full form, and the Vision Transformer, is the next lecture.

Chapter 21

Transfer learning and fine-tuning

  • You rarely train an image model from scratch.
  • A model pretrained on ImageNet already knows generic visual features (edges, textures, and object parts), so you reuse that backbone and only teach it your task.
  • The real question is how much of it to retrain?

The three modes

  • Feature extraction: freeze the pretrained backbone and train only a new head. Cheapest and safest; best when data is scarce.
  • Fine-tune the top layers: unfreeze the upper blocks and train them at a low learning rate while keeping the early layers fixed. A middle ground.
  • Fine-tune everything: unfreeze all layers, still starting from pretrained weights. Adapts the most, but needs more data.

Which mode should I use?

PRACTICAL NOTES
  • Always replace the final head to match your number of classes.
  • Fine-tune with a smaller learning rate than you would use from scratch, so you nudge the pretrained weights rather than wreck them.
  • Freezing layers trains faster and uses less memory.
  • On small datasets, lean toward freezing and watch closely for overfitting.
